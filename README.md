# smile-minecraft/homebrew-tap

Homebrew tap for smile-minecraft projects.

```sh
brew tap smile-minecraft/tap
brew install smile-minecraft/tap/mc-asset
brew test mc-asset
```

The formula installs the public `mc-asset` v0.5.0 release and runs the render → analyze → validate smoke path.

## MacHelper

A menu bar system monitor, fan control and cleanup utility for macOS 14 and later.

```sh
brew install --cask smile-minecraft/tap/machelper
```
